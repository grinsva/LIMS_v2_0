# Официальная документация IntraSCADA

`https://docs.intrascada.com` — первоисточник по поведению продукта: свойства
элементов, команды, привязки, переменные клиента, скрипты визуализации.
Полное руководство — 691 страница, целиком его читать нельзя и не нужно.

Правило: перед правкой незнакомого элемента, команды или привязки открыть
**одну-две страницы по теме**, а не листать руководство.

## Как обратиться адресно

В скилле есть скрипт `scripts/docs.js`. Он работает без зависимостей, кэширует
страницы локально и принимает как `id` (`pg037`), так и `alias` (`button`).

```bash
node scripts/docs.js page button              # страница целиком, Markdown
node scripts/docs.js page linkWithLocals      # по alias
node scripts/docs.js page pg207               # по id
node scripts/docs.js page button --raw        # без шапки-комментария
node scripts/docs.js page button --refresh    # заново с сайта

node scripts/docs.js tree --filter контейнер  # найти раздел
node scripts/docs.js search deviceValue       # поиск по тексту
```

Кэш: `%LOCALAPPDATA%\intrascada-docs\` (`tree-*.json`, `pages\<id>.md`).
Дерево обновляется раз в сутки, страницы — по `--refresh`. Кэш вне проекта,
в репозиторий не попадает.

Если скрипт недоступен, те же данные отдаёт HTTP API (можно через `webfetch`):

```text
https://docs.intrascada.com/restapi/tree?source=intrascada&lang=ru
https://docs.intrascada.com/restapi/page?source=intrascada&lang=ru&id=<id|alias>
https://docs.intrascada.com/restapi/search?source=intrascada&lang=ru&str=<текст>
```

## Что в доках уточнять чаще всего

- **Функции привязок:** `deviceValue(inData, 'value')`,
  `localValue('dev_id')`, `globalValue('serverTime')`,
  `deviceCommand(inData, 'state', '!')` и операторы `'+1'`, `'*1.5'`.
- **Стандартная переменная** `dev_id` («ID устройства») — её используют
  штатные диалоги; в проекте могут быть свои переменные.
- **Список команд кнопки** (переход на экран, диалог, `setval`, скрипт,
  снимок, печать, выход) и порядок нескольких действий на один клик.
- **Форматы изображений:** SVG (масштабирование и перекраска), PNG, JPG, GIF
  (не рекомендуется из-за нагрузки); в поле пути допустим URL из сети.
- **Возвращаемые значения свойств-списков:** `left/center/right`,
  `dotted/dashed/solid/...`, `disabled/db/raw/interval` и т. п.

## Правила использования

1. Документация авторитетна по **поведению продукта**; скилл — по **практике
   проекта** (пути, ID, регламент, проверенные особенности сборки).
2. Если документация и проверенное поведение расходятся — доверять проверке в
   клиенте/сборке, а расхождение сообщить пользователю.
3. Учитывать пометки «Добавлено v5.x»: в установке может быть другая версия.
4. Не копировать страницы в репозиторий (авторские материалы) и не сохранять
   PDF в проект: для работы достаточно кэша скрипта и ссылок.
5. В отчёте о задаче указывать, какой раздел использован: заголовок и URL.
